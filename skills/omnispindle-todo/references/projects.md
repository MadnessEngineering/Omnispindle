# Valid Omnispindle Projects

This document lists all valid project names in the Omnispindle system. Use these exact names when creating or querying todos.

## All Projects

- **madness_interactive** - Main interactive system
- **regressiontestkit** - Testing framework and utilities
- **omnispindle** - Core Omnispindle platform
- **swarmonomicon** - Swarm coordination system
- **hammerspoon** - Automation and scripting
- **intergrations** - System integrations (note: appears as "intergrations" in database)
- **cogwyrm** - Cognitive workflow engine
- **tooling** - Development tools and utilities
- **spindlewrit** - Documentation and writing tools
- **inventorium** - Inventory management system
- **Anathesmelt** - Data processing pipeline (capitalized)
- **other** - Miscellaneous tasks
- **tasker** - Task automation system
- **gateway_metrics** - API gateway metrics and monitoring
- **tinker** - Experimental and prototyping work
- **oculustestkit** - Testing toolkit for Oculus
- **anathesmelt** - Data processing pipeline (lowercase)
- **cleaning** - Code cleanup and maintenance tasks
- **faros** - Faros integration
- **agentic ai services** - AI agent services
- **ellie-demo** - Ellie demonstration project
- **replit-notes** - Replit integration notes
- **doh** - DNS over HTTPS
- **ellie-api** - Ellie API implementation
- **farossummittwo** - Faros Summit 2 project
- **ellie-guardian** - Ellie security and guardian features
- **war-room** - Crisis management and coordination
- **dadda2** - Dadda2 project
- **the_machine** - Core machine learning infrastructure
- **Morin** - Morin project

## Usage Tips

- Project names are case-sensitive
- Some projects have both capitalized and lowercase versions (e.g., Anathesmelt vs anathesmelt)
- Use exact spelling including underscores and hyphens
- "intergrations" is intentionally spelled differently from "integrations"
- For general tasks that don't fit other categories, use "other"
